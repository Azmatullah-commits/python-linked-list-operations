##  About This Repository

This repository contains my practice programs for **Singly Linked Lists using Python**.

These programs are part of my Data Structures and Algorithms (DSA) learning journey. I created this repository to practice linked list operations and improve my problem-solving skills.

## Operations Covered

| No. | Operation | Description |
|:---:|---|---|
| 1 | Count Nodes | Count total nodes |
| 2 | Find Maximum | Find the largest value |
| 3 | Insert After Value | Insert a new node after a given value |
| 4 | Delete Duplicates | Remove duplicate values |
| 5 | Delete By Value | Delete a node using its value |
